## 1. Project Overview

Smart E-Mobility Hub is a coordination system for shared electric mobility resources (e-bikes/e-scooters) across the VNU-HCM Urban Area. It manages Mobility Hubs consisting of parking spaces, charging points, and vehicles, serving two main actor groups: students (rent vehicles, reserve, charge) and operators (monitor, handle incidents, coordinate, run What-if Simulations).

The final report is graded on the full SE process: Requirements → Architecture → Structural/Behavioral Design → UI Design → What-if Simulation Design → Implementation → Testing → Evaluation, plus an AI Usage Declaration and a presentation + 3-minute demo video.

No hardware is used — vehicle, parking and charging-point state comes from simulated data generated by the IoT simulator (owned by M8, see below).
